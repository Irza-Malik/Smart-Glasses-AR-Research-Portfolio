# AI-Assisted Augmented Reality on Smart Glasses

### Final Year Project — BS Computer Engineering
COMSATS University Islamabad, Abbottabad Campus | 2026

**Project:** Real-Time Object Detection and Information Overlay Using Augmented Reality Glasses

This research project explores the integration of artificial intelligence, computer vision and augmented reality on resource-constrained wearable devices.

Two prototypes were developed and tested using Epson Moverio BT-300 smart glasses.

**Prototype 1 — Real-Time AR:** Continuous camera capture, YOLOv8 object detection, UDP communication, MediaPipe hand tracking and gesture-based virtual object interaction.

**Prototype 2 — Scene-Aware AR:** Event-driven image capture, AI-based object detection and segmentation, placement reasoning, collision analysis and foreground-aware occlusion of 3D furniture.

The project investigates the challenges of wearable AI, including processing latency, communication overhead and virtual model stability, and explores event-driven scene analysis as an alternative to continuous processing.
